## Security Policy

The security of PickleScript and its users is important to us.

If you discover a security vulnerability, please report it privately to the project maintainers rather than publicly disclosing it through GitHub issues.

Include as much detail as possible to help us understand and reproduce the issue. We will review reports and work to address confirmed vulnerabilities as promptly as possible.

Please avoid publicly disclosing vulnerabilities until the maintainers have had a reasonable opportunity to investigate and resolve them.
